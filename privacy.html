Recon 대시보드 · 개인정보 처리방침

2026년 10월 23일 판 · 처음으로

Recon 대시보드는 YouTube API 서비스를 써서, 대시보드에서 승인한 영상을 연결한 유튜브 채널에 올리고 채널 숫자를 읽습니다. 이 기능을 쓰면 YouTube 서비스 약관을 따르는 데 동의하는 것입니다. 구글이 다루는 정보에는 Google 개인정보처리방침이 적용됩니다.

받는 권한과 쓰는 곳

  • 동영상 업로드(youtube.upload): 승인한 영상을 올리는 데만 씁니다. 영상을 지우거나 고치는 권한은 받지 않습니다.
  • 내 채널 보기(youtube.readonly): 올리기 직전에 로그인한 채널이 올릴 채널과 같은지 확인하고, 채널의 구독자·조회수와 최근 영상 제목을 읽는 데 씁니다.
  • 유튜브 분석 보기(yt-analytics.readonly): 채널의 시청 시간·조회수 같은 숫자를 읽어 대시보드에 보여 주는 데만 씁니다.
  • 애드센스 보기(adsense.readonly): 운영자 애드센스 계정의 수익 숫자를 읽어 대시보드에 보여 주는 데만 씁니다. 설정을 바꾸는 권한은 받지 않습니다.
  • 구글 비밀번호는 이 프로그램이 보지도 받지도 않습니다. 로그인은 구글 화면에서만 합니다.

남기는 것

  • 로그인 열쇠(새로 고침 토큰): 운영자 PC에 윈도우 사용자 암호화(DPAPI)로 저장합니다. 다른 PC나 다른 윈도우 사용자는 풀 수 없습니다.
  • 올린 장부: 올린 시각, 영상 파일 지문, 채널 번호, 영상 번호, 제목, 공개 상태. 같은 영상을 두 번 올리지 않으려고 남깁니다.
  • 숫자 기록: 날마다 읽은 채널 숫자와 수익 숫자를 운영자 PC에 남깁니다.
  • 남긴 정보는 운영자 PC 밖으로 보내지 않고, 다른 사람이나 회사와 나누지 않습니다. 광고에 쓰지 않습니다.
  • 구글 API에서 받은 정보는 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

지우기와 권한 해제

  • 대시보드에서 '연결 끊기'를 하면 그 계정의 로그인 열쇠를 지웁니다. 장부와 숫자 기록은 요청하시면 7일 안에 지웁니다. 유튜브에 올라간 영상은 유튜브 스튜디오에서 지우셔야 합니다.
  • 언제든 Google 계정 보안 설정에서 이 앱의 권한을 해제할 수 있습니다. 해제되면 열쇠가 더는 통하지 않으며, 운영자 PC에 남은 그 계정 관련 기록도 7일 안에 지웁니다.
